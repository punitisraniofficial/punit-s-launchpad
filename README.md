# Punit's Launchpad

Create a modern, professional personal portfolio website for Punit Israni, a 1st-year B.Tech student based in Jaipur, India.



IMPORTANT DESIGN GOAL:

This should look like the portfolio of a talented young developer/student preparing for internships and opportunities — NOT the website of a senior software engineer, CEO, consultant, or corporate executive.



The visual identity should be:

- Modern

- Minimalist

- Premium

- Clean

- Slightly futuristic

- Student/developer focused

- Professional enough for recruiters

- Personal rather than corporate



Avoid excessive glassmorphism, neon colors, giant typography, excessive gradients, or flashy animations.

VISUAL SYSTEM

--------------------------------------------------



Use a sophisticated modern design system.



Typography:

- Inter

- Geist

- Manrope

or another clean modern sans-serif.



Use strong typography hierarchy.



Colors:

Prefer a restrained palette:

- Deep charcoal / near-black

- White/off-white

- One subtle accent color

- Very subtle gradients



Avoid rainbow gradients and excessive neon.



Background:

Use subtle:

- Grid

- Noise

- Gradient glow

- Soft geometric elements



But keep the background understated.



--------------------------------------------------

ANIMATION

--------------------------------------------------



Use animations sparingly.



Include:

- Smooth scrolling

- Fade/slide-in section reveals

- Subtle card hover effects

- Button micro-interactions

- Gentle image hover/parallax if appropriate



Do NOT make every element animate.



Respect prefers-reduced-motion.



--------------------------------------------------

RESPONSIVENESS

--------------------------------------------------



The website MUST be fully responsive.



Desktop:

Elegant spacious layout.



Tablet:

Maintain hierarchy without excessive shrinking.



Mobile:

Prioritize readability and usability.



The hero photo should remain visually strong on mobile.



Navigation should transform into a clean mobile menu.



--------------------------------------------------

TECHNICAL REQUIREMENTS

--------------------------------------------------



Prefer:



React / Next.js

Tailwind CSS

Lucide icons

Framer Motion or lightweight animation library



Use semantic HTML.



Optimize:

- Performance

- Accessibility

- SEO

- Mobile responsiveness

- Image loading

- Clean component structure



Use reusable components.



Keep personal information and project data in an easy-to-edit configuration/data file where possible.



--------------------------------------------------

IMPORTANT AUTHENTICITY RULE

--------------------------------------------------



This portfolio represents a FIRST-YEAR B.TECH STUDENT.



The website should show potential rather than pretending to show years of professional experience.



The overall impression should be:



"He's still early in his journey, but he's curious, technically inclined, actively building things, understands modern technology, and has the potential to become a strong developer."



NOT:



"Corporate CEO with 15 years of experience."



The design should be impressive because of its craftsmanship, not because of exaggerated claims.(The resume is attached in the conversation)
